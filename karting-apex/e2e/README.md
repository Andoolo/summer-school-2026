# E2E «Апекса»

Сквозные проверки того, что не видно модульным и интеграционным тестам: бот через настоящий
вебхук и веб-приложение в браузере. Запускаются в CI на каждый push (job **E2E · apex**)
и локально одной командой.

## Что проверяется

**Бот** ([`bot_e2e.py`](bot_e2e.py), 24 проверки) — API шлёт сообщения в имитатор Telegram Bot API
([`fake_telegram.py`](fake_telegram.py)), а «сообщения пользователя» приходят в вебхук API:

- вход через Telegram: ссылка → код сверки → контакт → сессия в приложении; код сверки текстом — подсказка;
- команды: `/start`, `/stop`, `/notify@бот`, `/whoami`, `/stats` (админу — сводка, остальным — справка),
  тишина в группах и на сообщения ботов, меню администратора;
- кнопка «Отменить бронь» в два шага — бронь отменена и в приложении;
- лист ожидания: последнее место занято → второй в очереди → отмена → предложение со ссылкой на заезд.

**Веб** ([`ui_e2e.py`](ui_e2e.py) + [`cdp.mjs`](cdp.mjs)) — собранное приложение в headless Chrome,
экран телефона 390×844:

- каталог: «Мест нет · 2-й в очереди» на своём заезде и «Мест нет · есть лист ожидания» на другом заполненном;
- экран заезда: срок предложения приходит с сервера («На запись будет 15 минут.»);
- сессия истекла на экране заезда → вход → открывается тот же заезд.

## Как устроено

[`run.sh`](run.sh) поднимает имитатор Telegram на хосте (порт 8099), Postgres и API через
`docker compose` (проект `apexe2e`, [`compose.e2e.yaml`](compose.e2e.yaml) поверх
`backend/compose.yaml`). Затем гоняет бота, собирает веб, раздаёт его на `127.0.0.1:8795`,
запускает Chrome с отладочным портом и гоняет проверки веба. В конце сохраняет логи и
останавливает стенд вместе с базой: каждый прогон начинается с чистого сида.

Скрипты не останавливаются на первой ошибке: каждая проверка печатает `OK` или `FAIL`, а в
конце — итог. Логи API, имитатора и веб-сервера и скриншоты экранов лежат в `e2e/out/`; в CI
это артефакт `e2e-apex`.

## Запуск локально

Нужны Docker, Python 3, Node 22+, JDK 17 и Chrome.

```bash
karting-apex/e2e/run.sh
```

- `SKIP_WEB_BUILD=1` — взять уже собранный веб (`client/webApp/build/dist/...`) и не ждать
  сборку ~8 минут;
- `KEEP=1` — оставить стенд после прогона (API на `:8090`, база в контейнере `apexe2e-db-1`);
- `CHROME=<путь>` — если Chrome не нашёлся сам.

На Windows скрипт запускается из Git Bash.
