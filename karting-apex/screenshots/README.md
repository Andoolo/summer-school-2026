# Скриншоты картинг-приложения «Апекс»

Положи сюда 3 PNG (подхватятся в `../README.md`):

- `login.png` — экран входа «АПЕКС»
- `slots.png` — список «Заезды» (трассы «Городское кольцо» / «Спортивная трасса», маршалы)
- `map.png` — карточка заезда с картой трассы (F1 + F2 на картинг-данных)

Как снять: запусти картинг-веб (`http://localhost:8091`), включи режим устройства (F12 → Ctrl+Shift+M
→ iPhone), пройди вход по dev-коду и сделай скриншоты (⋮ → Capture screenshot).
