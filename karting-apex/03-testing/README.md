# 03 · Тестирование (Блок 3)

Тестирование приложения «Апекс» (картинг-центр) с помощью ИИ. Три столпа (по методологии лекции Блока 3):

1. **Ревью требований** — сабагенты анализируют `01-analysis` на пробелы/нестыковки/нетестируемые
   формулировки и готовность к написанию тест-кейсов → [`requirements-review.md`](requirements-review.md).
2. **Генерация тест-кейсов** — план-таблица покрытия по экранам → детализация (компонентные +
   сценарные, позитив/негатив/edge, привязка к AC). Формат: Markdown (чтение) + YAML (машиночитаемый,
   под TMS/автоматизацию) → [`test-cases/`](test-cases/).
3. **Автотесты** — анализ покрытия + дописать автотесты (регресс на фичи Блока 2: B2/F1/F3) →
   [`autotests-report.md`](autotests-report.md).

## Принципы (из лекции)

- Верифицировать результаты ИИ, не доверять слепо.
- Разные агенты на разные задачи; консолидировать отчёты (пересечения/различия).
- Ревью «сверху вниз»: намерение → структура → детали.
- Хранить промпты и правила рядом с тестами (в git).

## Инструменты

- ИИ: Claude Code (+ сабагенты).
- Среда: Docker (Postgres + API), Go 1.25, Gradle/Kotlin 2.2.20 (KMP).
- Прогон: `go test ./...` (бэк), `./gradlew :shared:allTests` (клиент).
