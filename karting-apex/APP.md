# Картинг-приложение «Апекс» (доп)

Рабочее приложение под домен **Картинг-центр** — та же кодовая база, что и референс «Волна»
(Go backend + Kotlin Multiplatform клиент), переоформленная под картинг. Это «связывает блоки»:
анализ (`01-analysis`, картинг) → **приложение** (`backend/` + `client/`) → тестирование (`03-testing`).

## Полная изоляция от «Волны»

Картинг-версия запускается **отдельно** и не конфликтует с референсом «Волна»:

| | Волна (референс) | Картинг «Апекс» |
|--|------------------|-----------------|
| docker compose project | `backend` | **`apex`** (`name: apex` в compose) |
| API | `:8080` | **`:8090`** |
| PostgreSQL | `:15432` | **`:25432`** |
| Веб dev-сервер | `:8081` | **`:8091`** |
| Том БД | `backend_postgres-data` | `apex_postgres-data` |

## Что переоформлено под картинг

- **Сид-данные** (`backend/migrations/00002_seed_dev.sql`): трассы «Городское кольцо» (novice) /
  «Спортивная трасса» (experienced), маршалы Марат / Виктор, боксы/паддок, geometry = контур трассы.
- **UI-тексты клиента**: «Прогулки»→«Заезды», «Инструктор»→«Маршал», «прокатная доска»→«экипировка
  (комплект)», логотип «ВОЛНА»→«АПЕКС», «маршрут»→«трасса».
- **Порты**: клиент ходит на API `:8090` (`VolnaApiClient.DEFAULT_BASE_URL`), веб на `:8091`.

## Как запустить

```bash
# Backend (проект apex, порты 8090/25432)
cd backend && docker compose --profile app up -d --build
# миграции (Up-секции через psql в контейнере apex-db-1) — см. историю команд
# Веб-клиент (порт 8091)
cd client && ./gradlew :webApp:wasmJsBrowserDevelopmentRun
# открыть http://localhost:8091
```

> Проверено: `/slots` на `:8090` отдаёт картинг-данные (трассы/маршалы/geometry); клиент
> компилируется (`:shared:compileKotlinWasmJs` → BUILD SUCCESSFUL). «Волна» на 8080/8081 не затронута.

## Все три блока — под картинг

Проект `apex-karting` теперь цельный, все блоки про один домен:

| Блок | Где | Статус |
|------|-----|--------|
| 1 · Анализ | `01-analysis/` | ✅ требования/архитектура/дизайн (картинг) |
| 2 · Разработка | `backend/` + `client/` + `02-development/` | ✅ приложение + доки B1/B2/B3/F1/F2/F3 (картинг) |
| 3 · Тестирование | `03-testing/` | ✅ ревью требований + тест-кейсы (MD+YAML) + автотесты |

Проверено на картинг-инстансе (:8090): B1 (dev-код в ответе), F1 (geometry трассы «Городское
кольцо», 6 точек), `go test ./...` — зелёный; приложение работает на :8091.
