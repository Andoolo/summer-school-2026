# D1 · Дизайн: гоночная тема «Апекс»

> **Тип:** доработка дизайна · **Слой:** client (тема + UI-kit) · **Сложность:** низкая-средняя · **Статус:** ✅ реализовано

## Цель

После первичной ре-темы (тексты/данные) «Апекс» визуально оставался перекрашенной «Волной»:
бирюзовый бренд, пастельные «морские» градиенты, волновой характер. Задача — дать приложению
**собственную картинг-идентичность**, не ломая структуру экранов референса.

## Что сделано

1. **Палитра** (`core/theme/VolnaColors.kt`) — единая точка темы (проливается через MaterialTheme):
   - бренд: бирюза `#00A8A8` → **гоночный красный `#E10600`** (кнопки, ссылки, актив-табы, иконки);
   - текст: чуть глубже графит (`#15151E` / `#6E6E78`).
2. **Обложки карточек** (`uikit/KartingArt.kt`, новый) — вместо пастельных градиентов
   Canvas-арт: тёмный асфальт с градиентом + красная диагональная гоночная полоса (двойная) +
   **клетчатая лента финишного флага** (2 ряда) снизу. Подключён в трёх местах
   (список заездов, деталь заезда, мои записи) — один composable, без дублирования.
3. **Карта** (`map/RouteMapPreviewFallback.kt`) — «вода» стала **асфальтом** (графит), обочины —
   газоном, линия трассы и пин — красные: схема выглядит как трек, а не как акватория.
4. **Типографика** — без подключения TTF (в проекте нет пайплайна compose-resources; осознанный
   компромисс): гоночный характер стилями — заголовки экранов **CAPS + Black Italic + разрядка**
   (`ScreenTitle`), wordmark входа **«АПЕКС•»** (Black Italic + красная точка-«апекс»).

## Промпты ИИ

> **Промпт:** Приложение — перекрашенная «Волна»: бирюза и морские градиенты. Сделай картинг-тему:
> гоночный красный вместо бирюзы через центральную палитру; обложки карточек — асфальт + красная
> полоса + клетчатый финишный флаг (Canvas, один переиспользуемый composable); карту-схему — асфальт
> вместо воды; заголовкам — гоночную типографику (CAPS, сверхжирный курсив, разрядка) без
> подключения шрифтовых файлов.
>
> **Действие:** правка `VolnaColors` (одна точка), новый `KartingArt.kt`, замена трёх
> hero-плейсхолдеров, перекраска констант карты, стили `ScreenTitle`/`AuthLogo`.

## Известное ограничение

Перекрашена **полноэкранная карта** (шторка «Открыть карту», общий `RouteMapPreviewFallback`).
Мини-превью карты в карточке заезда и в «Деталях записи» — отдельные локальные composable
(`SlotDetailsMapPreview` / `BookingDetailsMapPreview`) со старой голубой схемой — видно на
скриншоте «Детали записи». Отмечено как follow-up (точечная перекраска констант).
