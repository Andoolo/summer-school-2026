# F4 · Фича: рекорды трассы (лидерборд лучших кругов)

> **Тип:** фича (доменная, full-stack) · **Слой:** backend (миграция + storage + handler) + client (DTO → стор → UI) · **Сложность:** средняя · **Статус:** ✅ реализовано

## Цель

Доменная картинг-фича, которой **нет в референсе «Волна»**: рекорды трассы. В картинге главная
метрика гонщика — **время круга**; у каждого прошедшего заезда есть результаты, а у каждой
конфигурации трассы — таблица рекордов. Фича связывает блоки: анализ (домен картинга) →
собственная разработка, а не только ре-тема референса.

## Требования

Прямого FR в ТЗ нет — фича добавлена как доменное расширение MVP (уровень «результаты заездов»
упоминается в брифе как ценность для клиента: следить за прогрессом). Инварианты: read-only
справочник, публичный (как `/slots`); лучший круг = `MIN(lap_time_ms)` по всем заездам клиента
на данной конфигурации.

## Реализация

**Backend:**
1. `migrations/00005_lap_results.sql` — таблица `lap_results` (booking_id FK CASCADE, lap_number,
   lap_time_ms, CHECK > 0), индекс по booking_id. **Только схема** (см. урок ниже).
2. `seed/karting_lap_results.sql` — демо-данные: 2 прошедших заезда, 3 гонщика (Иван/Ольга/Сергей),
   12 времён кругов. Применяется вручную к dev-БД, в тестовую БД не попадает.
3. `internal/storage/postgres/slots.go` — `Leaderboard(routeID, limit)`:
   `SELECT COALESCE(c.name,'Гонщик'), MIN(lap_time_ms), COUNT(*) ... GROUP BY c.id ORDER BY best ASC LIMIT 10`
   + отдельная проверка существования трассы (404).
4. `internal/http/handlers/catalog.go` — handler `Leaderboard` (позиции, JSON
   `{route_id, route_name, entries[{position,name,best_lap_ms,laps}]}`);
   `router.go`/`main.go` — ручной маршрут `GET /routes/{routeID}/leaderboard`
   (паттерн как `/auth/refresh`; публичный — консистентно с `/slots`).

**Client (Compose Multiplatform):**
5. `LeaderboardEntry` (domain) + DTO + маппер + `SlotRepository.leaderboard(routeId)` (Ktor).
6. `SlotDetailsStore` — рекорды грузятся **после** слота, non-blocking: при ошибке секция просто
   скрыта, карточка заезда работает как раньше.
7. `SlotDetailsScreen` — секция **«🏁 Рекорды трассы»** под ценами: топ кругов, P1 подсвечен
   гоночным красным, формат времени `41.890` / `1:01.234` (`toLapTimeText`).

## Урок (честно)

Первая версия положила демо-данные **в миграцию** — интеграционные тесты сразу упали
(конфликт UUID броней с тестовыми + лишние слоты сломали ожидания каталожных тестов). Это
хрестоматийное «миграции ≠ сид»: тестовая БД накатывает все миграции goose, поэтому демо-данные
живут в отдельном seed-файле. Поймано `go test ./...`, исправлено, перегнано — зелёный.
