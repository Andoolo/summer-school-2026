# Матрица ошибок API (единая)

> **Единая таксономия ошибок клиентского API.** Канон кодов — спецификация API
> ([`../api/`](../api/)). Источник локализованного текста — клиентское приложение (по коду ошибки
> и полям `details`). Применяется ко всем сценариям — [UC-1 запись](use-cases.md#uc-1-запись-на-заезд-себя-и-гостей),
> [UC-2 отмена](use-cases.md#uc-2-отмена-записи), [UC-4 вход](use-cases.md#uc-4-вход-по-sms-otp),
> [UC-5 профиль/аккаунт](use-cases.md#uc-5-управление-профилем-и-аккаунтом).

## Ошибки бронирования и слотов

| Код | HTTP | Обязательные `details` | UX-реакция | Retry | Источник UC |
| :-- | :-- | :-- | :-- | :-- | :-- |
| `slot_full` | 409 | `available_seats`, `available_rental_kits` | Показать актуальные свободные места-карты/прокатные комплекты, обновить карточку | Нет (изменить число мест) | UC-1 E1/E2/E3 |
| `double_booking` | 409 | `booking_id` | Сообщить, что бронь на слот уже есть; перейти в «Мои бронирования» | Нет | UC-1 E3 |
| `slot_cancelled` | 410 | `slot_id` | Сообщить об отмене слота центром, убрать CTA записи; повторная запись недоступна | Нет | UC-1 E5; FR-46 |
| `slot_started` | 422 | `slot_id`, `start_at` | Сообщить, что заезд начался/прошёл, запись и отмена недоступны | Нет | UC-1 E5; UC-2 E1 |
| `already_cancelled` | 409 | `booking_id` | Бронь уже отменена; показать текущий статус | Нет | UC-2 E2 |

## Ошибки авторизации и доступа

| Код | HTTP | Обязательные `details` | UX-реакция | Retry | Источник UC |
| :-- | :-- | :-- | :-- | :-- | :-- |
| `invalid_code` | 400/401 | — | Сообщение «неверный код», поле OTP остаётся активным | Да (ввод заново) | UC-4 |
| 401 (unauthorized) | 401 | — | Очистка токена, переход на авторизацию (R-016) | Да (после входа) | все UC |
| 403 (forbidden) | 403 | — | Сообщение об отсутствии прав; действие недоступно (клиент видит только свои брони) | Нет | NFR-12 |
| 404 (not_found) | 404 | — | Ресурс не найден (напр. бронь/слот) — показать «недоступно» | Нет | UC-2 |

## Сетевые и серверные ошибки

| Код | HTTP | Обязательные `details` | UX-реакция | Retry | Источник UC |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 429 (rate limit) | 429 | `retry_after` | Сообщение «слишком много попыток», отложенный повтор | Да (после `retry_after`) | UC-4; NFR-19 |
| 5xx (server error) | 5xx | — | Единый Error/Retry; для брони — повтор по тому же `Idempotency-Key` | Да | все UC |
| offline / timeout | — | — | Мутации запрещены (понятное сообщение); просмотр — из кэша с пометкой «данные могли устареть»; таймаут ~10 с | Да (Error/Retry) | UC-1 E4; UC-2 E3; NFR-24 |
