# User stories

> **Этап 2.** Пользовательские истории. Формат: «Как <роль>, я хочу <действие>, чтобы <ценность>».
> Каждой истории — критерии приёмки.
>
> **Скоуп: клиентское приложение и API для него** (роль «Клиент»). Функции маршала и владельца
> обеспечиваются существующей инфраструктурой и здесь не описываются.

| ID | Как (роль) | Хочу (действие) | Чтобы (ценность) | Критерии приёмки | FR |
| :-- | :-- | :-- | :-- | :-- | :-- |
| US-1 | Клиент | зарегистрироваться по имени и номеру телефона без пароля | быстро начать пользоваться без барьеров | Указав имя и телефон, получаю доступ; повторный вход — по номеру телефона; сложный пароль не требуется. | FR-1, FR-2 |
| US-2 | Клиент | видеть список предстоящих слотов заездов | выбрать подходящий заезд | По умолчанию показываются ВСЕ предстоящие слоты (`only_available=false`), отсортированные по времени старта; слот показывает дату/время, конфигурацию трассы, маршала, цену, всего/свободно мест-картов; заполненные (свободно = 0) и отменённые слоты остаются в списке с пометкой «Мест нет» и неактивной CTA записи; при отсутствии слотов — пустое состояние. | FR-9 |
| US-3 | Клиент | фильтровать список слотов | быстро находить подходящий вариант | Могу фильтровать по дате/периоду, типу конфигурации трассы (новичковая/опытная), наличию свободных мест, маршалу; внутри группы (тип конфигурации, маршал — множественный выбор) значения по «ИЛИ», между группами — по «И»; границы дат включительные, в локальной зоне; дефолт — без фильтров; пустой справочник маршалов — фильтр скрыт; активные фильтры отображаются; список обновляется по выбору. | FR-38 |
| US-4 | Клиент | открыть карточку слота со всеми параметрами | понять детали перед записью | Карточка показывает дату/время, конфигурацию трассы и тип, маршала, цену, всего/свободно мест-картов, доступность прокатной экипировки, место сбора и карту трассы. | FR-9a, FR-44 |
| US-5 | Клиент | записаться на выбранный слот | забронировать место-карт на заезд | После подтверждения создаётся запись; свободные места-карты уменьшаются; запись появляется в «Моих бронированиях». Итоговая цена показывается из `price_total` ответа API (сервер — источник истины). | FR-10, FR-45 |
| US-6 | Клиент | при записи указать свою или прокатную экипировку | приехать со своим шлемом/подшлемником или взять напрокат | Можно выбрать «своя» / «прокатная» для каждого места; «прокатная» уменьшает фонд прокатных комплектов, «своя» — нет. Карт всегда центра — выбор экипировки не влияет на занятость карта. | FR-11, FR-14 |
| US-7 | Клиент | одной записью забронировать несколько мест (себя + гости) | записать компанию за раз | Можно указать 1–3 места в одной записи при наличии свободных мест-картов; для каждого гостя выбирается вариант экипировки; данные гостей (имя/возраст/рост) не собираются. | FR-12 |
| US-8 | Клиент | быть защищённым от записи сверх лимита | не приехать на занятое/несуществующее место | Лимит мест `max_seats = min(free_seats, track_config.capacity_cap, 3)` (свободные места-карты, потолок конфигурации, лимит 3 на бронь); прокат экипировки проверяется **отдельно**: `rental_count ≤ free_rental_kits`; при гонке запросов двойная бронь/овербукинг исключены. | FR-13, FR-15 |
| US-9 | Клиент | видеть список своих бронирований | контролировать предстоящие и прошедшие заезды | Вижу свои записи (предстоящие и прошедшие) со статусом, параметрами слота, числом мест и вариантом экипировки. | FR-35a |
| US-10 | Клиент | отменить свою запись до старта | освободить место-карт, если планы изменились | Запись отменяется только целиком (частичная отмена гостя не поддерживается); при ранней отмене (≥2 ч, включая ровно 2 ч) освобождаются ВСЕ места-карты и прокатные комплекты брони; при поздней (<2 ч) запись помечается «поздняя отмена», места-карты не освобождаются, штрафов нет; время в UTC отображается в локальной зоне, статус отмены определяет сервер. | FR-16, FR-17, FR-18 |
| US-11 | Клиент | видеть цену заезда | понимать стоимость заранее | В карточке и при подтверждении показана цена; итог берётся из `price_total` ответа API (FR-45), не пересчитывается локально; оплата офлайн (наличные/перевод), запись фиксируется без онлайн-оплаты. | FR-30, FR-45 |
| US-12 | Клиент | получать напоминание о предстоящей записи | не забыть и не пропустить заезд | Заблаговременно до старта приходит напоминание через **системный push** (нативное/гибридное приложение, APNs/FCM); SMS/email — Phase 2. *(Should)* | FR-33 |
| US-13 | Клиент | просматривать ранее загруженные данные офлайн | ориентироваться у трассы при нестабильной связи | При отсутствии сети вижу ранее загруженный список слотов и свои брони с пометкой «данные могли устареть»; изменяющие действия (бронь, отмена) офлайн недоступны с понятным сообщением; единый Error/Retry для повторной загрузки. | FR-9, FR-35a |
| US-14 | Клиент | быть защищённым от двойной брони при сбое сети | не получить дубль и не переплатить | Клиент при создании брони передаёт обязательный `Idempotency-Key`; при неопределённом результате повтор с тем же ключом и телом даёт идентичный ответ и не создаёт дубль. | FR-10, FR-13 |
| US-15 | Клиент | видеть понятные сообщения об ошибках | понять причину и что делать дальше | Для ключевых операций ошибки отображаются по единой матрице (код → реакция): нехватка мест/экипировки, двойная бронь, отменённый/стартовавший слот, неверный код, лимит запросов, серверная ошибка; текст локализован; где уместно — предлагается повтор. | FR-10, FR-16 |
| US-16 | Клиент | подтвердить вход кодом из SMS | войти безопасно без пароля | Ввожу телефон → получаю одноразовый код в SMS → ввожу код и вхожу; при неверном коде поле остаётся активным, есть лимит попыток и повторной отправки; номер маскируется в UI и логах. | FR-43 |
| US-17 | Клиент | узнать об отмене заезда центром (погода/форс-мажор) | не приехать впустую и понять причину | При отмене заезда центром моя бронь не исчезает, а получает статус «Отменён центром» с причиной; приходит push-уведомление; повторная запись на этот слот недоступна (кнопка неактивна). | FR-46, FR-33 |
| US-18 | Клиент | управлять профилем и аккаунтом | поправить данные или удалить учётку | Могу посмотреть и отредактировать имя и телефон (смена телефона — с подтверждением кодом); при удалении аккаунта активные брони аннулируются и освобождают места-карты, прошедшие — анонимизируются. | FR-47, FR-48 |
| US-19 | Клиент | выйти из аккаунта | завершить сессию на чужом/общем устройстве | По нажатию «Выйти» сессия закрывается, токены очищаются из защищённого хранилища, при следующем входе — снова OTP по телефону. | FR-49 |

> **Вне скоупа.** Истории маршала и владельца, а также оценки маршалов обеспечиваются существующей
> инфраструктурой и в клиентском приложении не реализуются.
