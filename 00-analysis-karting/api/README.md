# API «Апекс» — клиентский контракт (OpenAPI)

> Многофайловая OpenAPI-спецификация клиентского API картинг-центра «Апекс». Точка входа для
> сборки — `openapi.yaml`; домены разложены по папкам. Формат совместим с Redocly CLI
> (`redocly bundle`/`lint`).

**Скоуп:** только то, что потребляет клиентское мобильное приложение (роль «Клиент»). Слоты,
конфигурации трасс и маршалы — read-only проекция существующего бэкенда; брони и профиль —
ресурсы, которыми оперирует клиент.

## Домены

| Домен | Папка | Что покрывает | Экраны |
| :-- | :-- | :-- | :-- |
| **auth** | [`auth/`](auth/) | Запрос SMS-кода, проверка кода, refresh пары токенов, logout | SCR-001 |
| **profile** | [`profile/`](profile/) | Профиль клиента, смена телефона (с OTP), удаление аккаунта | SCR-007 |
| **slots** | [`slots/`](slots/) | Список/фильтрация слотов и карточка слота (read-only) | SCR-002, SCR-003 |
| **bookings** | [`bookings/`](bookings/) | Создание брони (идемпотентное), список броней, отмена | SCR-004, SCR-005, SCR-006 |
| **marshals** | [`marshals/`](marshals/) | Справочник маршалов для фильтра (read-only) | BS-001 |
| **common** | [`common/`](common/) | Общие модели: `Error`, пагинация, типы money/datetime | все |

## Сквозные правила

- **Аутентификация:** `Authorization: Bearer <access_token>` (`bearerAuth`), кроме
  `auth/requestCode` и `auth/verifyCode`. При `401` клиент делает refresh; при неуспехе — выход.
- **Идемпотентность:** `POST /bookings` требует заголовок `Idempotency-Key` (R-022).
- **Ошибки:** единая модель `Error` с `code` и `details`; канон кодов —
  [матрица ошибок](../2-requirements/error-matrix.md).
- **Время:** все `datetime` — ISO-8601 UTC (суффикс `Z`); бизнес-правила — в зоне центра,
  отображение — в зоне устройства клиента (R-021).
- **Валюта:** все денежные суммы — RUB (копейки, int64) либо decimal-string в `price_total`.
- **Безопасность:** только HTTPS (TLS 1.2+, NFR-18); ПДн (телефон) маскируются в логах.

> **Ключи/секреты НЕ входят в контракт:** API-ключ Яндекс.Карт, push-сертификаты APNs/FCM,
> секреты SMS-провайдера — параметры окружения бэкенда/клиента, в OpenAPI не описываются.
