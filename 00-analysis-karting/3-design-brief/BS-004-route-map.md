# BS-004 · Карта трассы

> Bottom Sheet: интерактивная карта Яндекс с отрисованной трассой и местом сбора.

**Зона:** АЗ · **Приоритет:** Medium · **Связанные требования:** FR-9a, FR-44 / UC-1, US-4

## Назначение

Показать трассу и место сбора в увеличенном интерактивном виде: клиент ориентируется, как проехать
к центру и где собрать группу.

## Навигация

- **Входящая:** тап по карте на SCR-003 / SCR-006.
- **Исходящая:** закрытие (кнопка/свайп вниз) → возврат на исходный экран.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Интерактивная карта (Яндекс.Карты) | Зум/панорамирование |
| Выделенная линия трассы | Полилиния `geometry` конфигурации |
| Пин места сбора | `meeting_point` + координаты |
| Текстовый адрес места сбора | Под картой / в шапке |
| Кнопка закрытия | Закрыть шторку |

## Поведение и валидации

- **Геометрия обязательна** (RR-D07): трасса рисуется по `geometry`.
- **Ключ Яндекс.Карт — параметр окружения**, не в коде/репозитории (NFR-26).
- **Fallback** при недоступности карт/квоты: только текстовый адрес/координаты без карты (как в
  [foundations §8](00-foundations.md), SCR-003, SCR-006); возврат на исходный экран (FR-44, NFR-23).

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| Карта недоступна (нет сети/квота) | Текстовый fallback адреса/координат |

## Применяемые логики

- [LOGIC-006] Карта трассы (Яндекс.Карты + fallback).

## Требования

FR-9a, FR-44 / UC-1, US-4 / NFR-26.
