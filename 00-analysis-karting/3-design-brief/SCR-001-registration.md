# SCR-001 · Регистрация / Вход

> Экран неавторизованной зоны. Вход по номеру телефона с подтверждением кодом из SMS (SMS OTP),
> для нового клиента — также ввод имени.

**Зона:** НЗ · **Приоритет:** Critical · **Связанные требования:** FR-1, FR-2, FR-43 / UC-4, US-1, US-16

## Назначение

Минимальный порог входа: лёгкая регистрация и повторный вход по телефону без пароля (NFR-3).
Трёхшаговый поток: телефон → код из SMS → имя (только для нового клиента).

## Навигация

- **Входящая:** запуск при отсутствии сессии; возврат после logout (UC-5 A1) и удаления аккаунта
  (UC-5 A2); 401-flow при истёкшем refresh (NFR-18).
- **Исходящая:** после успешного входа → SCR-002 Список слотов.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Поле «Телефон» | Ввод/редактирование номера с маской и нормализацией формата |
| Кнопка «Получить код» (primary) | Запрос OTP (rate-limited) |
| Поле «Код из SMS» (появляется после запроса) | Ввод одноразового кода (6 цифр) |
| Ссылка «Отправить код повторно» | Повторный запрос OTP (с учётом лимитов) |
| Поле «Имя» (только для нового клиента) | Имя при первой регистрации |
| Кнопка «Войти» / «Продолжить» (primary) | Подтверждение входа |

## Поведение и валидации

- **Телефон:** валидация и нормализация формата; кнопка «Получить код» disabled до валидного номера.
- **OTP-ввод:** поле активно после запроса; ввод 6 цифр; автоматическая отправка на проверку при
  заполнении.
- **Антифрод (NFR-19):** не более ~1 запроса кода в 30–60 с, не более ~5/час на номер/устройство;
  число попыток ввода ≤5 до временной блокировки; код имеет TTL.
- **Новый vs существующий клиент:** после успешной проверки кода сервер определяет, новый ли клиент;
  новый → ввод имени (FR-1); существующий → сразу авторизация (UC-4 A1).
- **Токены:** пара access/refresh сохраняется в защищённом хранилище (Keychain/Keystore, NFR-18).

## Состояния (помимо [паттерна §5](00-foundations.md))

| Состояние | Поведение |
| :-- | :-- |
| Неверный код (`invalid_code`) | Поле OTP остаётся активным; «Неверный код»; счётчик попыток |
| Лимит запросов кода (429) | «Отправить повторно» с таймером до `retry_after` |
| Код просрочен/не пришёл | «Отправить код повторно» (с учётом лимитов) |
| Нет сети | Запрос кода недоступен; понятное сообщение |

## Применяемые логики

- [LOGIC-001] OTP-авторизация (запрос/проверка кода, антифрод, хранение токенов).

## Требования

FR-1, FR-2, FR-43 / UC-4 / US-1, US-16 / NFR-3, NFR-18, NFR-19, NFR-20.
