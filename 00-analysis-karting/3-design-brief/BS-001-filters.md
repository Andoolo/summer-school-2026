# BS-001 · Фильтры

> Bottom Sheet фильтрации списка слотов.

**Зона:** АЗ · **Приоритет:** High · **Связанные требования:** FR-38 / UC-3, US-3

## Назначение

Уточнить список слотов под запрос клиента: дата/период, тип конфигурации трассы, наличие мест,
маршал.

## Навигация

- **Входящая:** кнопка «Фильтры» на SCR-002.
- **Исходящая:** «Применить» / «Сбросить» → SCR-002 с обновлённым списком.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Пресеты дат | «Сегодня / Эта неделя / Выходные» |
| Кастомный диапазон дат | Поля «с / по» (включительные границы, локальная дата) |
| Тип конфигурации (множественный) | Чекбоксы: новичковая / опытная (ИЛИ внутри группы) |
| Маршал (множественный) | Чекбоксы из справочника маршалов (ИЛИ внутри группы) |
| «Только со свободными местами» | Опция `only_available` (по умолчанию выкл.) |
| «Применить» (primary) / «Сбросить» | Применить/очистить фильтры |

## Поведение и валидации

- **Семантика (R-026):** внутри группы (`route_type`, `marshal_id`) — **ИЛИ**; между группами —
  **И**. Границы дат включительные; даты — в локальной зоне.
- **Пустой справочник маршалов:** фильтр по маршалу **скрывается** (UC-3 A4).
- **Активные фильтры** отображаются на SCR-002 после применения.
- Пресеты и диапазон маппятся в `date_from`/`date_to`.

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| Нет слотов под фильтрами (после применения) | На SCR-002 — empty с «Сбросить фильтры» |
