# SCR-005 · Мои бронирования

> Список броней клиента с разбивкой на предстоящие/прошедшие.

**Зона:** АЗ · **Приоритет:** Critical · **Связанные требования:** FR-35a / UC-2, US-9

## Назначение

Контроль предстоящих и прошедших заездов клиента. Видит только свои брони (NFR-12).

## Навигация

- **Входящая:** таб «Мои бронирования»; кнопка «Мои бронирования» на BS-002.
- **Исходящая:** тап по брони → SCR-006.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Сегмент/группы | «Предстоящие» / «Прошедшие» (разбиение на клиенте по `slot.start_at`) |
| Карточка брони | Статус, параметры слота, число мест, вариант экипировки, `price_total` |
| Пагинация | `limit`/`offset` (вся история, включая отменённые и поздние) |

## Поведение и валидации

- **Вся история** (FR-35a): активные, отменённые, поздние отмены (`late_cancel`), отменённые
  центром (`club_cancelled`), прошедшие.
- **Разбиение «предстоящие/прошедшие»** — на клиенте по `slot.start_at`; «прошедшесть» —
  производное, не отдельный статус.
- **Сортировка** по `slot.start_at`.
- **Только свои брони** (NFR-12).

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| Empty (нет броней) | «У вас нет броней» + «Выбрать заезд» → SCR-002 |
| Loading | Скелетон карточек |
| Error / offline | Кэш с пометкой «данные могли устареть» + «Повторить» |

## Применяемые логики

- [LOGIC-008] Паттерн состояний экрана.

## Требования

FR-35a / UC-2, US-9 / NFR-12, NFR-24.
