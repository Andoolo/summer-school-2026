# SCR-002 · Список слотов

> Главный экран авторизованной зоны — каталог заездов; точка входа в сценарий записи.

**Зона:** АЗ · **Приоритет:** Critical · **Связанные требования:** FR-9, FR-38 / UC-3, US-2, US-3

## Назначение

Показать клиенту предстоящие заезды, дать отфильтровать их и перейти к карточке/записи. По
умолчанию — слоты на ближайшие 7 дней, без скрытия заполненных.

## Навигация

- **Входящая:** после входа (SCR-001); таб «Заезды»; возврат с карточки/феном.
- **Исходящая:** тап по карточке слота → SCR-003; кнопка «Фильтры» → BS-001; таб-бар → SCR-005,
  SCR-007.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Карточка слота | Дата/время старта, конфигурация трассы и тип (бейдж), маршал, цена, всего/свободно мест-картов |
| Бейдж «Мест нет» | На заполненных слотах (`free_seats=0`); CTA записи disabled |
| Бейдж «Заезд отменён центром» | На слотах, отменённых центром (`slot_cancelled`); CTA записи disabled |
| Кнопка «Фильтры» | Открытие BS-001; индикатор активных фильтров |
| Pull-to-refresh | Обновление доступности мест |
| Таб-бар | Заезды / Мои бронирования / Профиль |

## Поведение и валидации

- **Окно по умолчанию (R-027):** ближайшие 7 дней (`date_from=now`, `date_to=now+7д`); больший
  период — фильтром дат.
- **Заполненные и отменённые не скрываются:** на заполненных (`free_seats=0`) — бейдж «Мест нет»,
  на отменённых центром (`slot_cancelled`) — бейдж «Заезд отменён центром» (разные ситуации,
  разные бейджи, см. [foundations §6](00-foundations.md)); в обоих случаях CTA записи disabled
  (R-012); по умолчанию `only_available=false`.
- **Сортировка:** по времени старта (ближайшие выше).
- **Применённые фильтры** отображаются (чипсы/индикатор).
- **Цена** — из данных слота (`price`); итог брони считается сервером (FR-45).

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| Loading | Скелетон карточек |
| Empty (нет слотов под фильтрами) | «Заездов не найдено» + «Сбросить фильтры» |
| Empty (нет расписания вовсе) | «Заездов пока нет — загляните позже» |
| Error / offline | Кэш с пометкой «данные могли устареть» + «Повторить» |
