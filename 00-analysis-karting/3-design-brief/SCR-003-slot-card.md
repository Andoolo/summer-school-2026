# SCR-003 · Карточка слота

> Полные параметры заезда перед записью, включая карту трассы и место сбора.

**Зона:** АЗ · **Приоритет:** Critical · **Связанные требования:** FR-9a, FR-44 / UC-1, US-4

## Назначение

Показать все параметры заезда, чтобы клиент решил записаться: дата/время, конфигурация трассы и
тип, описание, маршал, цена, всего/свободно мест-картов, доступность прокатной экипировки, место
сбора и карта трассы.

## Навигация

- **Входящая:** тап по карточке слота на SCR-002.
- **Исходящая:** «Записаться» → SCR-004 (если `free_seats > 0` и слот активен); тап по карте →
  BS-004; «Назад» → SCR-002.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Дата/время старта | В локальной зоне устройства клиента |
| Конфигурация трассы + тип (бейдж) | Название + «новичковая/опытная» |
| Описание конфигурации | Текстовое описание заезда (`description`) |
| Маршал | Имя маршала слота |
| Блок цены | `price` за место-карт; «Своя экипировка — бесплатно; прокат — отдельно» |
| Всего/свободно мест-картов | Счётчик доступности |
| Доступность прокатной экипировки | `free_rental_kits` комплектов свободно |
| Карта трассы (статичный превью) | Яндекс.Карты с выделенной линией трассы (`geometry`) |
| Место сбора | Пин + текстовый адрес (`meeting_point`) |
| Кнопка «Записаться» (primary, нижний CTA) | Переход к оформлению записи |

## Поведение и валидации

- **CTA «Записаться» disabled**, если `free_seats = 0` (бейдж «Мест нет») или слот отменён
  (`slot_cancelled`).
- **Карта обязательна** (RR-D07): тап → BS-004 интерактивная карта. **Fallback** при
  недоступности Яндекс.Карт: адрес/координаты текстом, без интерактивной карты (FR-44, NFR-26).
- **Место сбора — обязательный элемент.**
- **Иконка «Поделиться»** — декоративна/неактивна в MVP (RR-D06, Phase 2).

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| Заполнен (0 мест) | «Мест нет» + CTA disabled |
| Слот отменён центром | «Заезд отменён центром» + причина; CTA disabled |
| Карта недоступна | Текстовый fallback адреса/координат |
| Loading / Error | По [паттерну §5](00-foundations.md) |

## Применяемые логики

- [LOGIC-002] Расчёт доступности (`max_seats`, `free_rental_kits`).
- [LOGIC-006] Карта трассы (Яндекс.Карты + fallback).

## Требования

FR-9a, FR-44 / UC-1, US-4 / NFR-1, NFR-26.
