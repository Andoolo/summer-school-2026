# BS-003 · Подтверждение отмены

> Bottom Sheet: объяснить последствия отмены (правило 2 часов) и подтвердить действие.

**Зона:** АЗ · **Приоритет:** High · **Связанные требования:** FR-17, FR-18 / UC-2, US-10

## Назначение

Показать правило 2 часов и текущий прогноз типа отмены (ранняя/поздняя), подтвердить отмену
целиком.

## Навигация

- **Входящая:** «Отменить запись» на SCR-006.
- **Исходящая:** «Подтвердить отмену» → SCR-006 с обновлённым статусом; «Не отменять» → SCR-006.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Текст правила 2 часов | Канон дословно: «Можно отменить бесплатно за 2 часа до старта. Позже ваше место в заезде за вами сохранится, но карт простаивает.» ([foundations §6](00-foundations.md)) |
| Прогноз типа отмены | «Ранняя отмена — места вернутся» / «Поздняя отмена — места не вернутся, штрафа нет» |
| Кнопка «Подтвердить отмену» (деструктивный) | Отмена всей брони |
| Кнопка «Не отменять» (secondary) | Закрытие без отмены |

## Поведение и валидации

- **Прогноз типа отмены** считается на клиенте по `slot.start_at` в **зоне центра** (R-021), но
  **финальный статус определяет сервер**. При расхождении — применяется серверный (UC-2 A2).
- **Граница «ровно 2 часа»** = ранняя отмена (FR-17).
- **Отмена целиком** (R-014): отменяется вся бронь со всеми местами и экипировкой.

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| Sending | Кнопка в загрузке; шторка остаётся открытой |
| Нет сети (offline) | Кнопка «Подтвердить отмену» disabled + понятное сообщение (мутация офлайн запрещена, [foundations §5](00-foundations.md); UC-2 E3) |
| Ошибка (5xx/таймаут) | Снек ошибки; шторка открыта — можно повторить |
| Слот стартовал (422) | «Заезд уже начался — отменить нельзя»; закрытие шторки |

## Применяемые логики

- [LOGIC-004] Правило 2 часов отмены.

## Требования

FR-17, FR-18 / UC-2, US-10 / NFR-21.
