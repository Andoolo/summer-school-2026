# SCR-006 · Детали брони + отмена

> Полная информация о брони и запуск отмены (только целиком).

**Зона:** АЗ · **Приоритет:** Critical · **Связанные требования:** FR-16–18, FR-46 / UC-2, US-10, US-17

## Назначение

Показать детали записи и статус, дать отменить её (целиком) до старта заезда. Отобразить статус
«Отменён центром» при отмене слота организатором/по погоде.

## Навигация

- **Входящая:** тап по брони на SCR-005; возврат с BS-003.
- **Исходящая:** «Отменить запись» → BS-003 (если старт в будущем и бронь активна); тап по карте →
  BS-004; «Назад» → SCR-005.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Статус брони | active / cancelled / late_cancel / club_cancelled (+ «Прошедшая» как производное) |
| Дата/время, конфигурация + тип, маршал | Параметры слота |
| Карта трассы (статичный превью) | Яндекс.Карты с трассой (`geometry`) |
| Место сбора | Пин + текстовый адрес (`meeting_point`) |
| Число мест, вариант экипировки | Параметры брони |
| `price_total` | Итог (read-only) |
| Причина отмены (для `club_cancelled`) | Текст причины из push/ответа |
| Кнопка «Отменить запись» (primary/деструктивный) | Запуск отмены (только целиком) |

## Поведение и валидации

- **CTA «Отменить» доступна** только пока заезд не стартовал (`start_at` в будущем) и бронь
  `active`. После старта — недоступна (UC-2 E1, `slot_started`).
- **Повторная отмена** уже отменённой записи не выполняется (`already_cancelled`, UC-2 E2).
- **Отмена только целиком** (R-014): нельзя отменить часть мест/гостей.
- **Тип отмены определяет сервер** по `slot.start_at` (граница 2 ч — в **зоне центра**, R-021):
  ≥2 ч → `cancelled` (места-карты и прокат возвращаются), <2 ч → `late_cancel` (не возвращаются,
  без штрафа). Граница «ровно 2 ч» = ранняя. Отображение времени — в зоне устройства клиента.
- **`club_cancelled`** (отмена центром): статус + причина; CTA записи на такой слот неактивна;
  повторная запись запрещена.

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| active, старт в будущем | CTA «Отменить» активна |
| late_cancel | Бейдж «Поздняя отмена» + пояснение; CTA скрыта |
| club_cancelled | «Отменён центром» + причина; CTA скрыта |
| Прошедшая (start_at в прошлом) | CTA «Отменить» недоступна |
| Карта недоступна | Текстовый fallback адреса/координат |

## Применяемые логики

- [LOGIC-004] Правило 2 часов отмены.
- [LOGIC-006] Карта трассы (Яндекс.Карты + fallback).

## Требования

FR-16, FR-17, FR-18, FR-46 / UC-2, US-10, US-17 / NFR-21.
