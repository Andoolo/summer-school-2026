# SCR-004 · Оформление записи

> Сбор параметров брони и фиксация записи. Ключевой экран — здесь доменная логика картинга
> (места-карты vs прокатная экипировка).

**Зона:** АЗ · **Приоритет:** Critical · **Связанные требования:** FR-10–15, FR-30, FR-45 / UC-1, US-5–8, US-11

## Назначение

Собрать число мест (себя + до 2 гостей), выбор экипировки по каждому месту, показать итоговую
цену и подтвердить запись.

## Навигация

- **Входящая:** «Записаться» на SCR-003.
- **Исходящая:** «Записаться» (подтверждение) → BS-002 при успехе.

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Сводка слота (компактно) | Дата/время, конфигурация, маршал |
| Счётчик мест | Выбор 1–3 мест (себя + до 2 гостей) |
| Переключатель экипировки на каждое место | «Своя» / «Прокатная» (шлем + подшлемник) |
| Блок цены (итог) | `price_total` из API (read-only, не пересчитывается локально) |
| Кнопка «Записаться» (primary, нижний CTA) | Создание брони |

## Поведение и валидации

> **Два независимых лимита (картинг).** Карт всегда центра — выбор «своя/прокатная» относится
> **только к экипировке**, а не к карте.

- **Лимит мест-картов:** `max_seats = min(free_seats, track_config.capacity_cap, 3)` — счётчик мест
  не может превысить это значение (значения из данных слота/конфигурации, не хардкодим).
- **Лимит прокатной экипировки:** `rental_count ≤ free_rental_kits` — число «прокатных» мест не
  может превысить свободные комплекты.
- «Своя экипировка» занимает место-карт, но **не** уменьшает прокатный фонд; «прокатная» — занимает
  место-карт **и** один прокатный комплект.
- **Цена итога:** берётся из `price_total` ответа API (`price × seats_count + rental_price ×
  rental_count`, RUB); клиент **не пересчитывает** (FR-45). Предпросмотр цены обновляется при
  изменении состава (оценочно), но **финальный итог — серверный `price_total`**; при расхождении
  локального предпросмотра и серверного приоритет за сервером (FR-45).
- **Идемпотентность (R-022):** при подтверждении клиент генерирует и передаёт `Idempotency-Key`.
- **Запрет** записи сверх лимита мест или свободных прокатных комплектов (FR-13, FR-15); защита от
  двойной брони/овербукинга при гонке запросов (NFR-8).

## Обработка ошибок (UC-1 E1–E5, [матрица](../2-requirements/error-matrix.md))

| Ситуация | Реакция |
| :-- | :-- |
| Не хватает мест-картов (`slot_full`) | Актуальное число мест, обновить карточку |
| Не хватает прокатных комплектов | Предложить уменьшить прокатные / выбрать «свою» (UC-1 E2) |
| Двойная бронь (`double_booking`) | «У вас уже есть бронь на этот заезд» → переход в SCR-005 (UC-1 E3) |
| Гонка/слот заполнился | «Мест больше нет», обновить список |
| Слот отменён/стартовал (`slot_cancelled`/`slot_started`) | Соответствующее сообщение, CTA disabled |
| Сетевой сбой/таймаут | Error/Retry; повтор с тем же `Idempotency-Key` |
| Нет сети | Запись недоступна, понятное сообщение |

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| CTA disabled | Пока не выбрано ≥1 места или превышен лимит |
| `free_rental_kits = 0` | Опция «Прокатная» disabled с подсказкой «Прокат закончился» (можно только «своя») |
| Sending | CTA в состоянии загрузки; повторный тап заблокирован |

## Применяемые логики

- [LOGIC-002] Расчёт доступности (`max_seats`, `free_rental_kits`).
- [LOGIC-003] Расчёт цены (отображение `price_total`).
- [LOGIC-004] Правило 2 часов (не для создания, но контекст слота).
