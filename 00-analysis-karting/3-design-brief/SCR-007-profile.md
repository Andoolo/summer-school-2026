# SCR-007 · Профиль клиента

> Контактные данные, выход и удаление аккаунта (входит в MVP).

**Зона:** АЗ · **Приоритет:** Medium · **Связанные требования:** FR-1, FR-2, FR-47–49 / UC-5, US-18, US-19

## Назначение

Просмотр и редактирование имени и телефона, выход из аккаунта, удаление аккаунта. Доступ только к
собственным данным.

## Навигация

- **Входящая:** таб «Профиль».
- **Исходящая:** «Выйти» / «Удалить аккаунт» → SCR-001; смена телефона → UC-4 A2 (OTP на новый
  номер).

## Элементы экрана

| Элемент | Назначение |
| :-- | :-- |
| Поле «Имя» | Просмотр/редактирование |
| Поле «Телефон» (маскированный) | Просмотр; редактирование — с подтверждением OTP |
| Справочные пункты | Политика конфиденциальности, версия и т.п. |
| Кнопка «Выйти» | Logout (FR-49) |
| Кнопка «Удалить аккаунт» (деструктивный) | Удаление аккаунта (FR-48) с подтверждением |

## Поведение и валидации

- **Телефон маскирован** в UI (`+7 *** *** ** 67`, NFR-20).
- **Редактирование телефона** — модальный OTP-флоу, аналогичный шагам 1–4 SCR-001 (ввод нового
  номера → код из SMS → проверка), **без запроса имени** (имя уже есть); подтверждение кодом на
  новый номер (UC-4 A2).
- **Удаление аккаунта (FR-48, R-009):** обязательное подтверждение; активные брони аннулируются и
  освобождают места-карты и прокатные комплекты; прошедшие брони **анонимизируются** и сохраняются
  для учёта; ПДн клиента анонимизируются, номер освобождается для повторной регистрации.
- **Logout (FR-49):** токены очищаются из защищённого хранилища; переход на SCR-001.

## Состояния

| Состояние | Поведение |
| :-- | :-- |
| Подтверждение удаления | Модальный диалог «Удалить аккаунт?» (деструктивное действие) |
| Ошибка сохранения | Error/Retry; правки не применяются до подтверждения сервером |
| Удаление офлайн | Мутация недоступна; понятное сообщение, кнопка disabled |

## Применяемые логики

- [LOGIC-001] OTP-авторизация (смена телефона).

## Требования

FR-1, FR-2, FR-47, FR-48, FR-49 / UC-5, US-18, US-19 / NFR-11, NFR-12, NFR-20.
