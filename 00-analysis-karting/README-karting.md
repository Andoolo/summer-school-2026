# Apex Karting — клиентское приложение + API

> Летняя школа Surf по ИИ-кодингу. Сквозной проект: картинг-центр «Апекс».
> Блок 1 (Аналитика) → Блок 2 (Разработка) → Блок 3 (Тестирование), все этапы с ИИ.

---

## О проекте

**«Апекс»** — уличный картинг-центр. Клиентское мобильное приложение заменяет ручную запись на
заезды через Telegram/доску и устраняет двойные брони на карт. Скоуп поставки — **только роль
«Клиент»**: клиентское приложение + API для него. Бэкенд (расписание, маршалы, админка) уже
существует и выступает black-box источником истины; приложение потребляет его данные через API.

> **Граница скоупа.** Слоты (заезды), конфигурации трасс и маршалы приходят из существующего
> бэкенда через API — приложение их читает, но не создаёт и не редактирует. Гарантия
> «0 двойных броней» и атомарность операций — на стороне бэкенда; со стороны клиента эта граница
> закрывается контрактом API.

## Цифровая гигиена

Секреты (API-ключи Яндекс.Карт, push-сертификаты APNs/FCM, SMS-провайдер) **никогда** не
попадают в репозиторий — см. [`.gitignore`](.gitignore). Все ключи передаются через переменные
окружения или секреты CI.
