# Скриншоты

Положи сюда 3 PNG (их подхватит корневой `README.md`):

- `login.png` — экран входа «Волна»
- `slots.png` — список прогулок
- `map.png` — карточка слота с картой маршрута по реальной geometry (фичи F1 + F2)

Как снять: запусти веб-клиент (`http://localhost:8081`), пройди вход по dev-коду и сделай скриншоты
нужных экранов.
